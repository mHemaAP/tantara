6. Deviations and unfinished work
- Full Cases, Research Desk, Drafts, Calendar, Tasks, Clients, Community, filing bundles, and strategy authoring are later-phase pages. This phase provides real case/document read views needed by search and citations, but not the broader CRUD flows. Their home tiles and dashboard quick actions are disabled and labeled for a later phase.
- The backend contract exposes institution choices but no institution write operation, so Settings lists choices read-only. The contract also has no embeddings rebuild route, so that control is disabled and explains why.
- The collection selector currently offers only “All collections”; the contract provides `collection_id` for asking but no collection-list endpoint.
- Screenshots used the isolated test fixture because the backend was unavailable. No live API smoke test was possible in this worktree.
- The checked-in OpenAPI fallback is compact. `pnpm gen:api` refreshes it from the live backend OpenAPI endpoint when available.
- Google fonts are configured with system font-family fallbacks. Offline production build without access to Google Fonts was not verified.

7. Dashboard visual fidelity assessment against `frontend.png`
Matches: fixed midnight sidebar, gold scales illustration and serif wordmark, white search topbar and account controls, indigo active navigation, pale workspace background, four requested metric cards plus the two secondary metrics, violet Ask TANTARA panel, suggestions and scoping controls, upcoming schedule, activity feed, and quick-action area. Spacing, radii, borders, muted text, and status accents follow the supplied premium legal-workspace language.

Differs: this phase’s dashboard is a focused workspace page rather than the reference board’s multi-module canvas. It does not include the case-management table, document AI Read, draft generator, autofill, filing bundle/paperbook, or strategy advisor panels. The Ask panel and calendar share a row, followed by activity and quick actions. The reference’s photographic legal imagery is represented by original vector illustration assets. These differences reflect the Phase 2 route scope and the no-hotlinked-assets requirement.
