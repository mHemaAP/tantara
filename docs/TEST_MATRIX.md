# Backend API test matrix

This table enumerates all 80 paths in `backend/openapi.json` (snapshot at this branch). Generic CRUD cases are parameterized by resource; the OpenAPI-wide tests below dynamically enumerate protected operations and mutation request bodies, so they also cover routes added to the snapshot. List-envelope and pagination assertions are included where an operation exposes the standard paginated envelope. `N/A` means the cell does not apply to that route shape. The final column names the exercised route edge when a dedicated edge applies.

The reusable matrix tests are `test_all_protected_openapi_operations_reject_anonymous_requests`, `test_all_openapi_mutation_bodies_return_validation_envelope`, and `test_all_openapi_paginated_get_routes_validate_page_bounds`. `test_dead_model_is_honest_on_all_generation_and_assistance_surfaces` covers closed-port outcomes for Ask, session messages, AI Read, Drafts, Autofill, and Strategy; AI Read and Autofill explicitly report that they do not call a language model. There is no community-assistance generation route in this 80-path OpenAPI snapshot. Owner tests use a second advocate account where feasible, so the response is 404 rather than a role-based 403 that could reveal record existence.
