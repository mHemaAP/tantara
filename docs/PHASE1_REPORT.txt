6. LIMITATIONS / UNFINISHED

- This is a local-first foundation, not completion of every Phase 1 acceptance item. Domain entities mostly use JSON payload storage; SQLAlchemy table metadata and migration coverage are incomplete compared with the full requested normalized schema and constraints.
- Hybrid retrieval uses SQLite FTS5 and in-process cosine ranking; a persisted FAISS index is not connected. Cloud/Supabase adapters are not fully wired into ingestion/retrieval.
- Bundle PDF generation/download, generated cover/index pages, complete route-specific request/response schemas, full role authorization, per-route rate limits, true case strategy generation, robust Range streaming, and exhaustive endpoint ownership/validation tests are unfinished.
- Demo seeding creates six clients and twelve cases plus sample participants/tasks/hearings/notes, but not the requested extra users, generated sample legal/scanned PDFs, completed ingestion records, research/draft/community/bundle artifacts, or generated bundle PDF.
- Workflow A (upload→extract→index→ask→cite→page reference) was not run end-to-end against an authoritative document. The import attempt for the India Code Act PDF timed out; its failure was recorded in the corpus manifest. The live AI ask therefore correctly returned no_evidence with empty citations.
- Test suite has six tests, not the requested full endpoint matrix, scanned-PDF OCR/docx/corrupt/retry suite, or live-server workflow A.
