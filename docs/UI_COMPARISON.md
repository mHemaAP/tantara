# UI comparison evidence

The supplied mock is a visual reference for hierarchy, branding, and key workflows; it is not a pixel-matching requirement. Desktop captures use 1440×900 and mobile captures use 390×844. Route captures are produced by authenticated Playwright tests against the seeded API, including `tests/ui-parity.spec.ts`, `tests/workspace-time-captures.spec.ts`, and the module-specific specs under `frontend/tests/`.
